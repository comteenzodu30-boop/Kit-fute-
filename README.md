# Kit Futé
Site éditorial français sur les outils d'organisation, de création et d'automatisation.

## Publication GitHub Pages
1. Ouvrir Settings dans le dépôt, puis Pages.
2. Dans Build and deployment, choisir Deploy from a branch.
3. Choisir la branche main et le dossier / (root), puis Save.
4. Attendre quelques minutes et vérifier l'URL affichée.
